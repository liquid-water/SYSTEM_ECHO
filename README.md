# SYSTEM_ECHO

A futuristic video game where you dodge enemies that are red and collecting fragments along the way which are yellow.

Narrative ┑
"You restored your conscience after an unknown reason..."
"You weirdly remember this place..."
"You start to collect fragments to try remembering what happened..."
